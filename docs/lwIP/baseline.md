## 设备基线：未覆盖

当前没有可访问的参考车机、iPhone、VPN 禁用设备或低配 ARM 设备。
未采集 APK 安装后的 USB 速率、iOS、码率、温控、吞吐、延迟、CPU、PSS、GC、
线程、FD 或 A/B/A 测量。不能用 JVM 回环测试推导这些数值。

测量流程和预算沿用 performance.md，不更改预算。每次设备测量需记录候选提交、
APK SHA-256、Android/ABI/固件、USB 模式/速率、iPhone/iOS、分辨率/帧率/媒体码率、
温控状态、负载、采集命令、原始报告路径和退出码。

G0 的参考设备基线和协议抓包条件尚未满足；G1 的 VPN/无线设备冒烟亦未覆盖。
当前允许的工作为可独立验证的接口基础和宿主实验，不能宣称阶段验收通过。
